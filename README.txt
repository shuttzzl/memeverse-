MEMEVERSE — remixed edition
==========================

1. Open index.html in Chrome, Firefox, or Safari.
2. Keep background.png, index.html, styles.css, app.js, and favicon.svg together.
3. Internet access is required for the REAL internet meme images and the optional Rickroll video. The background, layout, filters, translator and aura checker all work locally.
4. To publish: upload the whole folder to GitHub Pages, Netlify, or another static-site host. No build steps or accounts are needed to run the site locally.

What changed:
- Kept the rainbow unicorn background, main heading, navigation and sticker.
- Removed the intro paragraph under the big headline.
- Replaced emoji cards with 15 authentic meme templates, each given its own funny caption through the Memegen.link image service.
- Added functioning filters, shuffle and personal reaction buttons.
- Added a working brainrot translator with text copy.
- Added an interactive aura checker.
- Kept Rickroll traps, with a close button and an external video fallback.
- Removed all drop shadows, auto-bouncing cards and unnecessary animations.

Meme content/credits:
Memegen.link (https://memegen.link/) is the rendering service for well-known internet meme formats. Each meme card links to its original format's source page.
